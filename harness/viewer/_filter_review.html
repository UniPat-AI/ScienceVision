Legend — what α / β / γ / δ mean
α broken remove. File is on disk but no working renderer / opens to nothing. Cannot be used for QA in any form.
β not-3D remove. Viewer opens the file, but the underlying content is 1D / 2D / text (band-plot curve, GDS layout, KB PDF) — fails the 3D-irreducibility test.
γ easyγ mediumγ hard keep — watch list. Real 3D, opens in viewer. Difficulty is a rule-based proxy; V-classify will overwrite once QA exists.
δ pending do NOT remove — but can't review here either. The 100 cad-native SLDPRT/STEP files are gitignored at crawl_data/*/0912_100_SLDFILES/* and not symlinked into this worktree. Review them in the main checkout or after H20 / modelscope sync.
About "no thumb": three flavors — by policy viewer has a dynamic preview, no static thumb needed (intentional); file not in worktree the asset itself is missing from this checkout (δ cad-native); renderable, not run file present + renderer exists, just hasn't run yet (the recoverable case).
