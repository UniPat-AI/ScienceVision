3D rendering limitation: USDZ is a zip of .usdc (binary USD) + textures. Full in-browser 3D rendering requires USD-WASM (~10 MB Emscripten build) or Apple Quick Look (macOS Safari only). This viewer takes the lightweight unpack route: unzip the USDZ in place → list files and texture thumbnails so the user can see the PBR material pipeline structure, but does not render geometry. For geometry rendering:
  • Open the USDZ file directly in macOS Safari to trigger Quick Look;
  • Or convert to glTF on the server with usd_to_gltf / usdzconvert and reuse /viewer/gltf.html.
