.SLDPRT / .SLDASM are SolidWorks-native closed binaries. No open-source toolchain reads them. To make this card render in 3D, drop one of:

  • .step — BREP precision (SolidWorks Desktop, Onshape, CAD Exchanger). Routes to OCCT viewer.
  • .glb — lossy mesh, free path (fabconvert.com → GLB, then tools/cad_native/import_meshes.py). Routes to glTF viewer.

Once either file lands at its expected path and tools/build_cad_native_manifest.py reruns, this card auto-promotes.
