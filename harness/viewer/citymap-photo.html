Google Maps Tiles API key required

Photorealistic 3D Tiles are served by Google. You need a free key (50,000 requests/month).

Setup (one time):
  1. Open Google Cloud Console → APIs & Services → Library
  2. Search "Map Tiles API" → click Enable
  3. Go to Credentials → Create credentials → API key
  4. Restrict the key to "Map Tiles API" only (recommended)
  5. Paste the key below ↓

Key is stored in your browser's localStorage only. It is sent directly to Google by your browser (never proxied through this server). Clear it any time via the "Clear key" button in the info panel.
