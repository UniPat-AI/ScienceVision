整体流程：导入专家名册 → 导入任务批次 → 分配任务 → 发布 → 专家在自己的工作台看到被分配的题目 → 回收并导入结果。

运营

分配与打包

按领域均衡的任务分发

操作指南：这一页做什么
  1. 01 自动均衡输入：选择一个批次 → 产出：按专家领域均衡生成的分配记录
  2. 02 指定分配输入：一个未分配任务加一位专家 → 产出：一条精确指定的分配记录
  3. 03 发布给全部专家输入：选择一个批次 → 产出：原子切换后的生效专家任务包；只有发布后，专家登录才看得到题目
  4. 04 构建离线交付包输入：批次、专家、输出路径与打包模式 → 产出：磁盘上的离线任务包
  5. 05 构建共享运行时输入：viewer 根目录与输出路径 → 产出：可被多个精简包复用的查看器运行时
  6. 06 导入历史任务包输入：历史任务包根目录，以及是否激活、是否允许缺失校验和 → 产出：登记进管理端的历史任务包

质检：下方「分配」表格中状态为 pending_review 的行会出现「通过 / 打回」按钮；打回必须填写原因，任务会退回该专家重做。用搜索框可按专家、状态、批次或领域筛选后抽检。
