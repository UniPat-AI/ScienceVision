操作指南：这一页怎么做

整体流程：左侧选题 → 在 3D 查看器里观察并截图取证 → 判定题目是否有效 → 写答案与推理过程 → 右上角提交结果。

  1. 01 选题输入：左侧「任务」列表，可用「未完成」筛选 → 产出：右侧显示题目、说明与对应的 3D 场景
  2. 02 观察场景输入：在 3D 查看器里拖拽旋转、滚轮缩放；右上角「专注查看器」把整个工作区交给查看器 → 产出：看清题目要判断的结构
  3. 03 采集截图输入：查看器上方工具条的「截图」按钮，再在弹窗预览里拖拽框选范围 → 产出：「复制选区」复制到剪贴板，或「下载 PNG」存成图片证据，并同时存下一份同名 JSON，记录任务、裁剪范围与截图时的视角
  4. 04 判定题目输入：「任务校验」选 有效／无效／不确定，并在「校验反馈」写清理由 → 产出：这道题本身的质量结论，管理员据此返修题目
  5. 05 作答输入：「答案」写结论，「推理过程」写关键判断依据，「尝试次数」记录这是第几次 → 产出：每次输入自动保存到本地，状态显示在表单下方
  6. 06 提交输入：右上角「提交结果」（在线）或「导出结果」（离线任务包）→ 产出：结果回到管理员端等待质检

查看器右上角那三个相机按钮来自 Mol* 自带的工具条，鼠标悬停即可看到中文提示：「重置缩放」（Reset Zoom）只改远近，把整个结构重新装进画面；「主轴摆正」（Orient Axes）按分子自身的主轴摆正，即把结构放平；「重置坐标轴」（Reset Axes）回到坐标系的 X／Y／Z 方向。后两个的差别就在于对齐的参照物：一个看分子形状，一个看坐标轴。

要量原子间距离：点查看器右上角的「切换选择模式」（Toggle Selection Mode）进入选择模式，依次点中两个原子，再展开左侧面板 → 「结构工具」（Structure Tools）→「测量」（Measurements）→「距离」（Distance），画面上就会标出以 Å 为单位的距离；量完再点一次同一个按钮退出，避免后面的点击继续加选。

结构文件常常只带非对称单元，周期镜像分子默认不在画面里。要看镜像：展开左侧面板 →「结构」（Structure）区的结构预设按钮，选「晶体接触」（Crystal Contacts，画出 5 Å 内的邻近镜像链，最适合判断最近接触）、「晶胞」（Unit Cell，填满整个晶胞）或「超胞」（Super Cell）；也可以在结构条目的「类型」（Type）里把「模型」（Model）换成「对称副本」（Symmetry Mates），并调其中的 radius 参数。这些入口只在文件带晶体对称信息时才出现——如果都找不到，说明该文件不含对称信息，请在「任务校验」里判为无效并写明原因。

推理过程只记语义关键的那几步：真正改变你判断的操作（例如放大一次仍看不清，于是继续放大到原子层级），不用记录每一次鼠标移动。在「录制 Ground Truth」面板里保存一步本身就是这样一次关键操作，所以每一条保存下来的步骤都要写说明，缺一条就提交不了。
