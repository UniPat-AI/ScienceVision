# Paper

**ScienceVision: Can AI Observe and Reason Like a Scientist?** (UniPat AI, Elorian AI) is
published on arXiv: [2611.04087](https://arxiv.org/abs/2611.04087).

The repository no longer carries a compiled PDF. arXiv is the canonical copy, so there is no
local file to hash or replace. [`resources/paper.json`](../resources/paper.json) records the
publication status, the author list, and the paper's license. The BibTeX entry is in the root
[README](../README.md#citation-and-license).

## Updating the record

When a new arXiv version is posted, update `resources/paper.json` (`verified_at`, `authors`,
`arxiv`, `url`, `license`, and `note`), the BibTeX entry in the root README, and this note. No
PDF is committed here.
